## 🚨 FAILURE MODES TO AVOID

```
1.  Title > 70 characters — YouTube truncates, ruins hook
2.  No keyword in title — kills discoverability
3.  No identity word — seniors won't click if not "for them"
4.  Generic description — first 150 chars MUST hook + keyword
5.  Tags in wrong language — ALL English, no Vietnamese
6.  Missing brand tags — "forever garden club" + "age proof rated" always
7.  No cross-links — every description needs 3+ internal links
8.  No series tease — pinned comment MUST mention next video
9.  Banned words in any field — check against Playbook word bank
10. Timestamps missing — placeholder OK but must be filled post-edit
11. > 15 tags — YouTube ignores excess, wastes effort
12. No engagement question — pinned comment must drive comments
13. Same tags every video — rotate Tier 2-3 per topic
14. Description < 200 words — too short for SEO juice
15. No disclaimer — medical/health adjacent = must include
```

## 💡 PRO TIPS

```
💡 Tip 1: Title Variant B is your "discovery insurance"
   If Variant A is optimized for existing subscribers (CTR),
   Variant B targets search (people who don't know you yet).
   Test both via YouTube A/B title testing (available since 2024).

💡 Tip 2: First 150 characters = your ENTIRE search listing
   Most viewers see ONLY title + first 2 lines of description.
   Front-load keywords + promise + emoji in those 150 chars.

💡 Tip 3: Timestamps boost watch time (YouTube rewards them)
   Videos with timestamps get "Key Moments" in search results.
   This gives you 3-5× more visual real estate in search.

💡 Tip 4: Pinned comment drives algorithm
   Comments in first hour = strong signal to YouTube.
   Pin YOUR comment immediately = guaranteed first comment.
   Engagement question = viewers reply = more comments = boost.

💡 Tip 5: Cross-linking is compound interest
   Every new video links to 3 old videos.
   After 30 videos: each video has 9+ inbound links.
   YouTube reads this as "deep library" = recommend more.

💡 Tip 6: Tags matter less in 2026 but still help
   YouTube uses tags for "topical clustering" — grouping your
   channel with similar content. Brand tags especially help
   YouTube understand "this channel = gardening + seniors."

💡 Tip 7: Update old descriptions monthly
   After publishing 10+ videos, go back to Video #1-5.
   Add new cross-links to newer videos.
   This creates a web, not a chain.
```
