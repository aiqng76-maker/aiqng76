# Thumbnail Vietnamese Senior Health V1.0

Skill chuyên dụng tạo prompt YouTube thumbnail cho kênh sức khỏe người Việt 50-75 tuổi. Học từ 4 video viral nhất của 100 Tuổi Khoẻ Mạnh (286K, 130K, 91K, 83K views).

**PRIMARY TOOLS:** Google Flow (Imagen 4), Midjourney v6+, Canva (text overlay).

**Output:** Prompts BẰNG TIẾNG ANH, text trong thumbnail BẰNG TIẾNG VIỆT.

---

## ⭐ STYLE: "Realistic Vietnamese Health Warning Thumbnail"

```
CORE DNA:
✓ Realistic photo (NOT watercolor, NOT illustration)
✓ Bác sĩ AI Việt nam (như Bác Sĩ Minh từ CHARACTER_DOCTOR_PROMPTS.md)
✓ Close-up bộ phận cơ thể HOẶC food/object
✓ Mũi tên đỏ + vòng tròn vàng cảnh báo
✓ Text tiếng Việt CHỮ TO ĐẬM (Impact / Bebas Neue / Be Vietnam Pro Bold)
✓ Màu chữ: ĐỎ ĐẬM hoặc VÀNG sáng trên nền tối
✓ Dark gradient background hoặc blurred medical
✓ Để chừa khoảng trống (negative space) cho text

NOT:
✗ Watercolor / illustration / cartoon
✗ Mặt phương Tây / Hàn / Nhật
✗ Text quá nhiều (>5 từ chính)
✗ Composition rối, nhiều focal point
✗ Light/cheerful (audience trên 50 phản ứng với CẢNH BÁO)
```

## 🎨 COLOR PALETTE & TYPOGRAPHY

### COLORS (Vietnamese Senior Health)

```
PRIMARY:
- Background dark: #0F1A2E (navy đậm) hoặc #1A1A1A (đen)
- Warning red: #E63946 (đỏ cảnh báo)
- Highlight yellow: #FFD60A (vàng sáng)
- Doctor coat white: #FFFFFF
- Skin tone: warm Asian #E8C4A0
- Sage green (food): #8A9A78
- Burnt orange (warm): #C97A3B

ACCENT:
- Tick green: #06D6A0
- Cross red: #E63946
- Arrow red: #DC2626 (mũi tên đỏ đậm)
- Circle yellow: #FACC15 (vòng tròn cảnh báo)
```

### TYPOGRAPHY (Vietnamese Display)

```
PRIMARY FONT (Big Text):
- Be Vietnam Pro Black (free, Google Fonts) — RECOMMEND
- UTM Avo (free, Việt) — alternative
- Anton (free, Google Fonts) — Western
- Size: 100-180pt
- Color: Vàng #FFD60A hoặc Đỏ #E63946
- Stroke: Đen 4-8px outline cho readability

SECONDARY FONT (Tag/Parenthetical):
- Be Vietnam Pro Bold
- Size: 50-80pt
- Background: Yellow chip #FFD60A với chữ navy
- Hoặc: Red chip #E63946 với chữ trắng

DOWNLOAD:
- Be Vietnam Pro: fonts.google.com/specimen/Be+Vietnam+Pro
- UTM Avo: tải free từ utmwebsite hoặc fontvn

DON'T USE:
✗ Roboto / Arial regular (quá nhạt)
✗ Script fonts (khó đọc)
✗ Comic Sans (không chuyên nghiệp)
```

## 🚨 FAILURE MODES

```
1. Style watercolor — phải REALISTIC photo
2. Mặt phương Tây/Hàn — phải Việt rõ rệt
3. Text font Roboto/Arial — phải Be Vietnam Pro Black
4. Text quá dài (>5 từ chính) — phải ngắn gọn, đọc 2 giây
5. Light/cheerful tone — audience 50+ phản ứng với CẢNH BÁO
6. Composition rối — 1 focal point chính
7. Background quá sáng — phải tối để chữ nổi
8. Bỏ qua negative framing — TITLE và VISUAL phải fear-driven
9. Skip parenthetical tag — Pattern B/C bắt buộc có
10. Text không có outline — chữ phải có viền đen 6px
```
