## 🏷️ CHANNEL NAME FRAMEWORKS

### 4 Naming Patterns (theo data đối thủ)

```
PATTERN 1: NUMBER + BENEFIT (như "100 Tuổi Khoẻ Mạnh")
- "100 Tuổi Khoẻ Mạnh" (đối thủ flagship)
- "80 Tuổi Tươi Trẻ"
- "Sống Trọn 100 Năm"
- "120 Năm Khoẻ Mạnh"

PATTERN 2: AUTHORITY + NICHE
- "Bác Sĩ Giấc Ngủ"
- "Chuyên Gia Tim Mạch 50+"
- "Bác Sĩ Tâm — Sức Khoẻ Người Cao Tuổi"

PATTERN 3: NICHE LOCK + EMOTIONAL
- "Ngủ Ngon Sau 50"
- "Tim Khoẻ Tuổi 60"
- "Trí Nhớ Vàng"
- "Sức Khoẻ Vàng"

PATTERN 4: ASPIRATIONAL
- "Sống Khoẻ Mỗi Ngày"
- "Bí Quyết Sống Thọ"
- "Khoẻ Như Tuổi 30"
- "Già Mà Khoẻ"

NAMING RULES:
✓ 3-5 từ là sweet spot
✓ Có age trigger ("50", "60", "100")
✓ Có niche keyword (giấc ngủ, tim, não)
✓ Tiếng Việt thuần (KHÔNG mix tiếng Anh)
✓ Dễ tìm trên YouTube search
✗ Tránh tên cá nhân (kênh personal khó scale)
✗ Tránh tên dài >7 từ
✗ Tránh từ tiếng Anh (audience 50+ ít quen)
```
