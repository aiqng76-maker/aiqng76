## 🎨 STYLE GUIDE: "ELEVATED RUSTIC PAINTERLY THUMBNAIL"

### CORE AESTHETIC (Same as video images — brand consistency)

```
✓ Painterly photorealistic HYBRID
✓ Late golden hour lighting (warm amber, directional)
✓ Shallow depth of field, creamy bokeh
✓ Warm earth-tone palette
✓ Cedar raised bed visible when appropriate
✓ Negative space for text (LEFT side typically)
✓ Premium magazine editorial quality
✓ NOT: stock photo, cartoon, anime, dark cinematic, vintage paper
```

### COLOR PALETTE (THUMBNAIL-SPECIFIC)

```
BACKGROUND TONES:
  Soft garden green bokeh: dominant for plant shots
  Warm cream: for text zone (left side gradient)
  Deep forest: dark zone behind bright text

TEXT COLORS:
  Primary text:     #FFFFFF (pure white) — on dark/green background
  Alt primary:      #2C3E2D (deep forest) — on light/cream background
  Highlight bar:    #C8A96E (honey gold) — behind secondary text
  Warning text:     #C47D4E (terracotta) — for Lottery CAPS
  Badge text:       #7A9E7E (sage green) — for small labels

SIGNATURE ELEMENTS:
  Cedar bed edge:   Warm sepia wood texture, bottom 8% of frame
  Age-Proof badge:  Small sage circle, "★★★★★" or year
```

### TYPOGRAPHY (CRITICAL — Different from video text)

```
PRIMARY (main thumbnail text):
  Font: MONTSERRAT BOLD or EXTRA BOLD
  Size: 72-96px equivalent (fills 25-35% of frame width)
  Color: White #FFFFFF (on dark bg) or Deep Forest #2C3E2D (on light bg)
  Case: ALL CAPS or Title Case
  Position: Left 55% of frame, vertically centered
  Drop shadow: subtle, 2px, 50% opacity black

SECONDARY (highlight bar text):
  Font: MONTSERRAT BOLD
  Size: 48-56px equivalent
  Color: Deep Forest #2C3E2D on Honey Gold #C8A96E bar
  Bar: Solid rectangle, rounded corners optional
  Position: Below primary, same left alignment

LOTTERY CAPS (for Pattern B, D, I):
  Font: MONTSERRAT BLACK
  Size: 84-96px
  Color: White on terracotta background OR Terracotta #C47D4E direct
  Energy: CAPS, larger, more aggressive than Lighthouse

SMALL BADGE (year, "SENIOR-TESTED", etc.):
  Font: Montserrat Medium
  Size: 28-32px
  Position: Bottom-left corner
  Background: Small sage green circle or pill shape
```

## 🔄 PATTERN AUTO-SELECTION LOGIC

```
IF title contains "[Number] Plants/Vegetables/Perennials/Flowers"
   → Var A: Pattern A | Var B: Pattern A (mismatch) | Var C: Pattern H

IF title contains "[Pest] HATE / Won't Touch / FLEE"
   → Var A: Pattern B | Var B: Pattern I | Var C: Pattern H

IF title contains "Build / Create / Weekend / How to"
   → Var A: Pattern C | Var B: Pattern A (plant focus) | Var C: Pattern H

IF title contains "STOP / Mistake / Regret / Don't"
   → Var A: Pattern D | Var B: Pattern B (before/after) | Var C: Pattern H

IF title contains "System / Plan / Age-Proof / Rules"
   → Var A: Pattern E | Var B: Pattern C (build) | Var C: Pattern H

IF title contains "Tools / Equipment / Saved"
   → Var A: Pattern F | Var B: Pattern A (plant context) | Var C: Pattern H

IF title contains month name or "Season"
   → Var A: Pattern G | Var B: Pattern A (plant hero) | Var C: Pattern H

IF title contains "Snakes / Disease / Kill / Danger"
   → Var A: Pattern I | Var B: Pattern B (split) | Var C: Pattern H

NOTE: Variation C is ALWAYS Pattern H (Brand Anchor — minimal text).
This provides maximum contrast in A/B/C testing and builds long-term
brand recognition as a "different looking" option in the test.
```

## 📋 VERSION SPECS

### VERSION 1: WITH TEXT (AI generates text in image)
```
- Midjourney/Flux tries to render text directly in image
- Include text specification in prompt
- May produce clean text (30% success) or gibberish (70%)
- If clean → fastest workflow (no Canva needed)
- If gibberish → use Version 2
```

### VERSION 2: NO TEXT (Add in Canva post-production)
```
- AI generates ONLY visual, zero text
- Left 55% of frame is mostly negative space (blurred garden/bokeh)
- User adds text in Canva using Typography specs above
- Guaranteed clean result every time
- RECOMMENDED for production reliability
```

## 🚨 FAILURE MODES TO AVOID

```
1.  Wrong style — Must be Elevated Rustic Painterly, NOT stock photo
2.  Too much text — Maximum 5 words visible, senior eyes need BIG
3.  Dark background — Golden hour WARM, not dark cinematic
4.  Wrong font — Montserrat Bold/Black, NOT serif (thumbnails ≠ video)
5.  Missing negative space — Left 55% must have room for text overlay
6.  All 3 look same — Variations MUST be visually distinct at small size
7.  Var C has too much text — Brand Anchor = 0-2 words, image dominant
8.  Forgot mismatch — Var B should have +2-4 number (if listicle)
9.  Cedar motif wrong — Present for Lighthouse patterns, absent for Lottery
10. Neon/saturated — NEVER. Warm earth tones only.
11. Margaret full face — NEVER. Hands or back ONLY.
12. Portrait orientation — ALWAYS 16:9 horizontal
13. Unreadable at phone size — Postage stamp test is NON-NEGOTIABLE
14. Same pattern 3× — Each variation must use DIFFERENT pattern
15. Forgot Canva specs — Version 2 MUST include exact text instructions
```

## 💡 PRO TIPS

```
💡 Tip 1: Montserrat is FREE on Google Fonts
   Download: fonts.google.com/specimen/Montserrat
   Install → available in Canva font picker

💡 Tip 2: The postage stamp test saves CTR
   Shrink thumbnail to 160×90 on your monitor
   If you can't read it → text too small
   If you can't tell topic → visual too complex
   If it blends with other thumbs → needs more contrast

💡 Tip 3: Honey gold bar (#C8A96E) is your CTR weapon
   This specific warm gold behind dark text = scroll-stop
   Don't use on every video (max 60%) to prevent fatigue
   A/B test: gold bar vs no bar

💡 Tip 4: Variation C wins more than you expect
   Image-dominant thumbnails (Pattern H) often win for senior
   audiences because they're CALMER in a busy feed
   Track: if C wins 3+ times → shift to 50% image-dominant

💡 Tip 5: Save EVERY winner in Playbook Section 8
   When CTR > 8%: document full prompt + seed + text spec
   Replicate 5× minimum before changing formula
   Your "house style" emerges from winners, not from planning

💡 Tip 6: Seasonal color tinting works
   Spring thumbnails: slightly more green in bokeh
   Summer: more amber/gold intensity
   Fall: add warm orange tones to background
   Winter: slightly cooler (but NEVER cold blue)

💡 Tip 7: The "one plant" rule for Pattern A
   Don't show 15 plants in thumbnail (too busy)
   Show THE MOST BEAUTIFUL ONE plant large
   Number tells viewer "there are 15" — plant shows quality
```
